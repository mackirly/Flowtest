# Исправление ошибки авторизации при запуске тестов

## Проблема
При запуске автоматизированного теста возникала ошибка:
```
test-cases.js:1930 GET http://localhost/api/testcases/runs/32/ 401 (Unauthorized)
```

Несмотря на то, что пользователь был авторизован.

## Причина
В функции `monitorTestExecution` на строке 1932 файла `test-cases.js` использовался неправильный ключ для получения токена авторизации из localStorage:

```javascript
// Было:
'Authorization': `Bearer ${localStorage.getItem('access_token')}`,

// Стало:
'Authorization': `Bearer ${localStorage.getItem('flowtest_access_token')}`,
```

## Решение
Исправлен ключ токена с `'access_token'` на `'flowtest_access_token'` в строке 1932.

## Что было проверено
1. Проверен весь файл `test-cases.js` на наличие других неправильных использований токена - больше не найдено
2. Проверены все JavaScript файлы в папке `/frontend/js` - неправильных использований не найдено

## Как проверить исправление
1. Откройте страницу тест-кейсов
2. Выберите проект
3. Найдите автоматизированный тест
4. Нажмите кнопку "Run Test"
5. Должен появиться прогресс-бар без ошибок авторизации
6. В консоли браузера не должно быть ошибок 401

## Дополнительная информация
Правильный ключ токена `'flowtest_access_token'` используется во всех остальных частях приложения, включая:
- API клиенты в `/frontend/js/api/`
- Страницы авторизации
- Другие страницы приложения

Это была единственная строка с неправильным ключом.
