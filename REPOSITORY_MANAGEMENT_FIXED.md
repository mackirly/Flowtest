## Как проверить

1. **Запустите систему**:
   ```bash
   cd "/mnt/d/Flowtest 2.0"
   docker-compose up -d
   ```

2. **Откройте настройки**:
   - Перейдите на http://localhost:3000
   - Войдите в систему
   - Перейдите в "Настройки" 
   - Откройте вкладку "Репозитории"

3. **Проверьте интерфейс**:
   ✅ Видите "Connected Repositories" вместо "coming soon"
   ✅ Есть кнопка "Add Repository"
   ✅ Есть настройки синхронизации
   ✅ Есть список репозиториев (пока пустой)

4. **Добавьте репозиторий**:
   - Нажмите "Add Repository"
   - Откроется модальное окно с формой
   - Заполните поля и протестируйте подключение
