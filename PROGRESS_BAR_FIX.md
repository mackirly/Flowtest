# Исправление прогресс-бара при запуске тестов

## Проблема
При запуске автоматизированного теста не появлялось окно с прогресс-баром.

## Что было исправлено

### 1. Добавлены функции управления прогресс-баром в `TestCasesPage`:

- `showTestProgressModal(testName)` - показывает модальное окно прогресса
- `hideTestProgressModal()` - скрывает модальное окно
- `updateTestProgress(percentage, title, message, status)` - обновляет прогресс
- `showProgressCloseButton()` - показывает кнопку закрытия

### 2. Обновлена функция `runTestCase()`:
- Теперь показывает прогресс-бар при запуске теста
- Отображает название теста в окне прогресса
- Обрабатывает ошибки с показом в прогресс-баре

### 3. Обновлена функция `monitorTestExecution()`:
- Обновляет прогресс-бар во время выполнения теста
- Показывает финальный статус (успех/провал/ошибка)
- Добавляет визуальные эффекты для разных статусов
- Автоматически обновляет историю запусков после завершения

## Как работает прогресс-бар

1. **Запуск теста**: Показывается окно с анимированной иконкой play
2. **Инициализация**: Прогресс 0-10%, статус "Подготовка к выполнению"
3. **Запущен**: Прогресс 20%, статус "Тест запущен"
4. **Выполнение**: Прогресс постепенно увеличивается до 90%
5. **Завершение**: Прогресс 100%, показывается финальный статус

## Визуальные индикаторы

- **Запуск**: Пульсирующая иконка play
- **Выполнение**: Вращающийся loader
- **Успех**: Зеленая галочка с зеленым свечением
- **Провал**: Красный крестик с красным свечением
- **Ошибка**: Оранжевый восклицательный знак
- **Пропущен**: Серая иконка пропуска

## Где можно запустить тест

1. **Из списка тестов**: Кнопка "Run Test" на карточке автоматизированного теста
2. **Из формы редактирования**: Кнопка "Запустить тест" для автоматизированных тестов
3. **Из контекстного меню**: Правый клик на тесте → "Run Test"

## Отладка

Если прогресс-бар не появляется:

1. Проверьте консоль браузера на наличие ошибок
2. Убедитесь, что элемент `test-progress-modal` присутствует в HTML
3. Проверьте логи:
   - `[TestCases] Running test case: <ID>`
   - `[TestCases] Showing test progress modal for: <Name>`
   - `[TestCases] Monitoring test execution: <RunID>`

## Тестирование

1. Откройте страницу тест-кейсов
2. Выберите проект
3. Найдите автоматизированный тест
4. Нажмите кнопку "Run Test"
5. Должно появиться окно прогресса с анимацией
