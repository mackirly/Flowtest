# FlowTest 2.0 - Reports Module

## Обзор

Новая система отчетов FlowTest 2.0 выполнена в стиле оригинального FlowTest с drag-and-drop интерфейсом, холстом для построения отчетов и панелью метрик.

## Основные возможности

### ✨ Шаблоны отчетов
- **Создание шаблонов**: Создавайте новые шаблоны отчетов с настраиваемыми метриками
- **Библиотека шаблонов**: Предустановленные шаблоны для основных типов отчетов
- **Дублирование**: Быстрое создание копий существующих шаблонов
- **Поиск**: Быстрый поиск по названию, описанию и типу шаблона

### 🎨 Визуальный редактор
- **Drag & Drop**: Перетаскивайте метрики из панели на холст
- **Интерактивный холст**: Перемещайте и изменяйте размеры элементов
- **Автоматические графики**: Графики создаются автоматически с реальными данными
- **Предварительный просмотр**: Просмотр отчета перед генерацией

### 📊 Типы метрик

#### Выполнение тестов
- **Test Summary** - Круговая диаграмма результатов тестирования
- **Execution Trend** - Тренд успешности выполнения во времени
- **Test Duration** - Длительность выполнения тестов

#### Покрытие
- **Feature Coverage** - Покрытие функций
- **Requirement Coverage** - Покрытие требований

#### Производительность  
- **Performance Trend** - Тренд производительности
- **Bottlenecks** - Узкие места в тестах

#### Качество
- **Defect Density** - Плотность дефектов
- **Quality Trend** - Тренд качества

### Основные классы

#### `FlowTestReports`
Главный класс, управляющий всей функциональностью:
- Загрузка и отображение шаблонов
- Управление drag & drop
- Создание и редактирование шаблонов
- Генерация отчетов

#### `ChartUtils`
Утилиты для работы с графиками:
- Создание различных типов графиков
- Управление данными
- Темизация (светлая/темная тема)
- Обновление графиков

## Использование

### Создание нового шаблона

1. Нажмите кнопку **"New Template"**
2. Заполните название, описание и выберите тип
3. Нажмите **"Create Template"**
4. Перетащите нужные метрики на холст
5. Сохраните шаблон кнопкой **"Save"**

### Редактирование шаблона

1. Выберите шаблон из левой панели
2. Перетащите дополнительные метрики или удалите существующие
3. Перемещайте элементы на холсте
4. Изменяйте размеры элементов, потянув за угол
5. Сохраните изменения

### Генерация отчета

1. Выберите настроенный шаблон
2. Нажмите **"Generate Report"**
3. Заполните параметры:
   - Название отчета
   - Проект
   - Формат (PDF, HTML, Excel)
   - Диапазон дат
4. Нажмите **"Generate"**

## Горячие клавиши

- `Ctrl/Cmd + S` - Сохранить текущий шаблон
- `Ctrl/Cmd + N` - Создать новый шаблон
- `Delete/Backspace` - Удалить выбранный элемент на холсте

## Настройка

### Добавление новых типов метрик

1. Добавьте конфигурацию в `ChartUtils.getChartConfig()`
2. Создайте HTML-карточку в панели метрик
3. Добавьте обработку в `getMetricContent()`

Пример:
```javascript
// В chart-utils.js
'new-metric': {
    type: 'bar',
    createFunction: 'createBarChart',
    options: { label: 'New Metric', unit: '%' }
}
```

### Кастомизация стилей

Основные переменные в `reports-flowtest.css`:
- `.template-card` - стили карточек шаблонов
- `.chart-element` - стили элементов на холсте
- `.metrics-panel` - стили панели метрик

## API интеграция

Для реальной интеграции замените mock-методы в `FlowTestReports`:

```javascript
// Вместо mockLoadTemplates()
async loadTemplates() {
    const response = await this.apiClient.get('/api/report-templates/');
    return response.data;
}

// Вместо mockSaveTemplate()
async saveTemplate(templateData) {
    const response = await this.apiClient.post('/api/report-templates/', templateData);
    return response.data;
}

// Вместо mockGenerateReport()  
async generateReport(reportData) {
    const response = await this.apiClient.post('/api/reports/generate/', reportData);
    return response.data;
}
```

## Адаптивность

Интерфейс адаптируется под разные размеры экранов:
- **Desktop** - полная раскладка с сайдбаром и панелью метрик
- **Tablet** - компактная раскладка
- **Mobile** - стековая раскладка с коллапсирующими панелями

## Печать

При печати отчета автоматически скрываются интерфейсные элементы, остается только содержимое холста с графиками.

## Темная тема

Система автоматически адаптируется к темной теме:
- Графики обновляют цветовую схему
- UI элементы переключаются на темные цвета
- Сохраняется читаемость и контрастность
