# FlowTest 2.0 Reports - Preview Feature

## 🎉 Новая функция предварительного просмотра

Теперь система отчетов FlowTest 2.0 поддерживает полнофункциональный предварительный просмотр с реальными графиками!

## ✨ Что добавлено

### 📊 **Реалистичные данные в графиках**
- **Test Summary**: Круговая диаграмма с процентным распределением
- **Execution Trend**: Линейный график с сезонными колебаниями
- **Performance Metrics**: Столбчатые диаграммы с реальными значениями времени
- **Coverage Analysis**: Процентное покрытие по модулям
- **Quality Metrics**: Радиальные диаграммы с многомерными оценками

### 🖼️ **Модальное окно предварительного просмотра**
- Полноэкранный режим
- Функция печати
- Заголовок отчета с метаданными
- Сводная информация с ключевыми метриками

### 🎨 **Улучшенная визуализация**
- Анимированное появление графиков
- Интерактивные подсказки (tooltips)
- Адаптивные размеры
- Поддержка темной темы

## 🚀 Как использовать

### 1. Создайте или выберите шаблон
```
1. Выберите любой шаблон из левой панели
2. Добавьте нужные метрики на холст
3. Расположите элементы как требуется
```

### 2. Откройте предварительный просмотр
```
1. Нажмите кнопку "Preview" в toolbar
2. Откроется модальное окно с отчетом
3. Все графики будут показаны с реальными данными
```

### 3. Дополнительные возможности
```
- Кнопка "Fullscreen" - полноэкранный режим
- Кнопка "Print" - печать отчета
- Закрытие по клику вне области или Esc
```

## 📊 Типы данных в предварительном просмотре

### **Test Summary (Круговая диаграмма)**
- Показывает реалистичное распределение Pass/Fail/Skip
- Процентные соотношения в легенде
- Интерактивные подсказки с количеством тестов

### **Execution Trend (Линейный график)**
- 12 месяцев данных с трендом
- Сезонные колебания
- Диапазон значений 65-98%

### **Performance Metrics (Столбчатые диаграммы)**
- Время выполнения в миллисекундах
- Различные категории тестов
- Цветовое кодирование по производительности

### **Coverage Analysis (Покрытие)**
- Процентное покрытие по модулям
- Реалистичные значения 60-98%
- Различные типы покрытия

### **Quality Metrics (Радиальная диаграмма)**
- Многомерная оценка качества
- 6 категорий качества
- Значения 70-95%

## 🛠️ Техническая реализация

### **Генерация данных**
```javascript
// Пример генерации реалистичных данных
generateRealisticData(metricType) {
    const generators = {
        'test-summary': () => ({
            passed: Math.floor(Math.random() * 20) + 70,
            failed: Math.floor(Math.random() * 15) + 5,
            skipped: Math.floor(Math.random() * 10) + 2
        }),
        'execution-trend': () => {
            // Генерация трендовых данных с сезонностью
            const seasonalFactor = Math.sin(i * 0.5) * 3;
            const trend = i * 0.3;
            const noise = (Math.random() - 0.5) * 6;
            return baseValue + seasonalFactor + trend + noise;
        }
    };
}
```

### **Создание графиков**
```javascript
// Улучшенные настройки Chart.js
createPreviewChart(canvas, metricType) {
    const previewData = this.generateRealisticData(metricType);
    const config = this.chartUtils.getChartConfig(metricType);
    
    return this.chartUtils[config.createFunction](ctx, previewData, {
        ...config.options,
        animation: {
            duration: 1000,
            easing: 'easeInOutQuart'
        }
    });
}
```
