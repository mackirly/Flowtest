## Как проверить

1. **Запустите систему**:
   ```bash
   cd "/mnt/d/Flowtest 2.0"
   docker-compose up -d
   ```

2. **Откройте настройки**:
   - Перейдите на http://localhost:3000
   - Войдите в систему
   - Перейдите в "Настройки"
   - Откройте вкладку "Репозитории"

3. **Добавьте репозиторий**:
   - Нажмите "Add Repository"
   - Заполните поля:
     - **Название**: Например "My Test Repo"
     - **Repository URL**: URL вашего GitHub/GitLab репозитория
     - **Ветка**: main или master
     - **Access Token**: Токен доступа (для приватных репо)
   - Нажмите "Test Connection" для проверки
   - Нажмите "Add Repository" для добавления

4. **Проверьте функционал**:
   - Синхронизация репозитория
   - Отключение репозитория
   - Список репозиториев обновляется в реальном времени

## API Endpoints

Теперь доступны следующие endpoints:

- `GET /api/automation/projects/` - Список всех репозиториев пользователя
- `POST /api/automation/projects/` - Добавить новый репозиторий
- `POST /api/automation/projects/test/` - Тест подключения к репозиторию
- `POST /api/automation/projects/{id}/sync/` - Синхронизация репозитория
- `DELETE /api/automation/projects/{id}/` - Удаление репозитория
