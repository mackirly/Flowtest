# Отладка истории запусков

## Проблема
История запусков не загружается при нажатии на вкладку "История запусков".

## Что было исправлено

1. **Frontend (test-cases.js)**:
   - Улучшена функция `switchTab()` для правильного переключения табов
   - Добавлена проверка наличия `currentTestCase` перед загрузкой истории
   - Улучшена обработка ошибок в `loadTestRunHistory()`
   - Обновлен дизайн карточек истории запусков

2. **HTML (test-cases.html)**:
   - Табы теперь правильно показываются для автоматизированных тестов
   - Функция `toggleAutomationSection()` управляет видимостью табов

## Как проверить

1. Откройте браузер и перейдите на страницу тест-кейсов
2. Выберите проект из выпадающего списка
3. Откройте любой автоматизированный тест-кейс
4. Нажмите на вкладку "История запусков"
5. Откройте консоль браузера (F12) и проверьте логи

## Возможные проблемы

1. **Тест-кейс не автоматизированный**:
   - Табы показываются только для автоматизированных тестов
   - Проверьте, что тип теста = "automated"

2. **Нет истории запусков**:
   - Если тест никогда не запускался, будет показано сообщение "История запусков пуста"

3. **Ошибка API**:
   - Проверьте логи backend: `docker-compose logs -f backend`
   - Проверьте сетевые запросы в браузере (вкладка Network)

## Проверка API напрямую

Можно проверить API через curl:

```bash
# Получить токен
TOKEN=$(curl -s -X POST http://localhost:8000/api/auth/login/ \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin"}' | jq -r .access)

# Проверить историю запусков
curl -H "Authorization: Bearer $TOKEN" \
  http://localhost:8000/api/projects/3/test-cases/5/test_runs/
```

## Логи для отладки

В консоли браузера должны быть видны следующие логи:
- `[TestCases] Switching to tab: history`
- `[TestCases] Loading test run history for test case: <ID>`
- `[TestCases] API response: <данные>`

Если логов нет или есть ошибки, проверьте:
1. Правильно ли загружен файл test-cases.js
2. Есть ли ошибки JavaScript в консоли
3. Правильно ли определен `testCasesPage` объект
