# Добавлен индикатор типа запуска в историю

## Что было добавлено

В карточки истории запусков добавлены два новых элемента:

### 1. Индикатор типа запуска
- **Автоматизированный** - синий бейдж с иконкой робота (ri-robot-line)
- **Ручной** - фиолетовый бейдж с иконкой руки (ri-hand-heart-line)

Индикатор отображается рядом со статусом запуска и четко показывает, как был выполнен тест.

### 2. Номер запуска
В правом верхнем углу каждой карточки теперь отображается ID запуска в формате #XX для лучшей идентификации.

## Визуальные изменения

```javascript
// Индикатор типа запуска
<span class="px-2 py-1 rounded-md text-xs font-medium ${
    run.run_type === 'automated' 
        ? 'bg-blue-100 text-blue-700 dark:bg-blue-900/30 dark:text-blue-300' 
        : 'bg-purple-100 text-purple-700 dark:bg-purple-900/30 dark:text-purple-300'
}">
    <i class="${run.run_type === 'automated' ? 'ri-robot-line' : 'ri-hand-heart-line'} mr-1"></i>
    ${run.run_type === 'automated' ? 'Автоматизированный' : 'Ручной'}
</span>

// Номер запуска
<div class="absolute top-3 right-3 text-xs text-gray-400 dark:text-gray-500">#${run.id}</div>
```

## Где это отображается

- На вкладке "История запусков" в форме редактирования тест-кейса
- В каждой карточке истории запусков
- Информация берется из поля `run_type` в API ответе

## Возможные значения run_type

- `automated` - автоматизированный запуск
- `manual` - ручной запуск

## Темная тема

Индикаторы корректно работают как в светлой, так и в темной теме:
- Светлая тема: яркие цвета фона с темным текстом
- Темная тема: приглушенные цвета фона со светлым текстом
